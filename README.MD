# Galactiforge
Download the 64-bit zipped version of Love 2D from:
https://love2d.org/

Unzip Love2D, open the folder and drag the Galactiforge folder onto the love.exe.

WASD to control the thrusters on the ship.
W controls thrusters pointing backward. 
A controls thrusters pointing left.
S controls thrusters pointing forward.
D controls thrusters pointing right.

E toggles block inventories.
N locks the camera to the ship direction.
<> selects different blocks.

Right click to remove a block
Left click to add a block

Space to fire ze cannons!

## Rust rewrite (Rust + Bevy)

The game is being rewritten in Rust. The original Lua/LÖVE code in `code/` is kept as a reference.

- `crates/gf_content`: data schema (RON files in `assets/content/`, generated by `python3 tools/gen_content.py`).
- `crates/gf_sim`: deterministic headless simulation that holds all game rules.
- `crates/gf_app`: Bevy client using the original 32x32 tileset.
- `crates/gf_bench`: stress benchmark.

Build and run:

    cargo run -p gf_app --release
    cargo test
    cargo run -p gf_bench --release -- 27 600

Linux needs these packages: libasound2-dev libudev-dev libx11-dev libxkbcommon-dev libwayland-dev.

Controls are shown in-game (press H to toggle the help).
